# PolyTrack AI Lab

Upload this folder to a GitHub repository and enable GitHub Pages from `main` / root.

The dashboard stores the supplied track code locally and runs a visible browser-only learning demo.

Important: a GitHub Pages page cannot directly control a separately opened official PolyTrack tab because of browser same-origin rules. The included `mod/` folder is a PolyModLoader-compatible starter for an actual in-game integration.

PolyTrack is created by Kodub; this is an independent experiment.
